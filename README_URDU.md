# 🕌 ایجنٹ اے ایم (Agent AM) - دی بیان یوٹیوب چینل منیجر
### خودکار اور خود مختار اے آئی ایجنٹ برائے اسلامی تاریخ و تعلیمی یوٹیوب چینل "The Bayaan"

---

## 📌 1. بنیادی تعارف (Introduction)
**Agent AM** ایک خود مختار، پائیدار، اور جدید ترین AI ایجنٹ ہے جو یوٹیوب چینل **"The Bayan"** کی مکمل خودکار نگرانی، روزانہ آڈٹ، اور کمیونٹی پوسٹنگ کو یقینی بناتا ہے۔

یہ سسٹم اینٹی گریویٹی (Antigravity)، براؤزر، یا لیپ ٹاپ بند ہونے کی صورت میں بھی **بیک گراؤنڈ ورکر (Background Worker)** اور **کلاؤڈ شیڈولر (Cloud Scheduler)** کے ذریعے 24 گھنٹے بلا تعطل چلتا رہتا ہے۔

---

## ⚙️ 2. بنیادی ترتیبات اور اوصاف (Key Specifications)
* **ایجنٹ کا نام:** Agent AM
* **چینل کا نام:** The Bayan
* **بنیادی موضوع:** مستند اسلامی تاریخ، خلافت راشدہ، اور سیرت النبی ﷺ
* **ٹائم زون:** `Asia/Karachi` (پاکستان کا معیاری وقت - PST)
* **یومیہ پوسٹنگ ہدف:** 1 کوئز (Quiz) اور 1 ٹیکسٹ پول (Text Poll)
* **پوسٹنگ ونڈو:** شام 6:00 بجے سے رات 9:00 بجے تک (PST)
* **رولنگ قطار (Rolling Horizon):** کم از کم 24 سے 48 گھنٹے آگے کا تصدیق شدہ مواد
* **رپورٹس کی زبان:** شستہ اور باوقار اردو

---

## 🏗️ 3. سسٹم کا آرکیٹیکچر (System Architecture)
1. **اردو ڈیش بورڈ اور ویب انٹرفیس (`agent_am/ui`):** ڈیسک ٹاپ اور موبائل دونوں کے لیے موزوں، جہاں لائیو شماریات، قطار، اور فوری کمانڈ بٹنز دستیاب ہیں۔
2. **اے آئی ریزننگ و ریسرچ انجن (`agent_am/services/ai_engine.py`):** گوگل جیمنائی اور چیٹ جی پی ٹی کے ذریعے اسلامی کتب کے مستند حوالوں کے ساتھ کوئز اور پولز کی تیاری۔
3. **یوٹیوب ڈیٹا سروس (`agent_am/services/youtube_service.py`):** یوٹیوب ڈیٹا اے پی آئی v3 کے ذریعے چینل کے ویوز، سبسکرائبرز، اور ویڈیوز کے اعداد و شمار کا حصول۔
4. **کمیونٹی پوسٹ مینیجر (`agent_am/services/community_post_service.py`):** یوٹیوب اسٹوڈیو آٹومیشن کے ذریعے کوئز اور پولز کی شیڈولنگ۔
5. **مستقل بیک گراؤنڈ شیڈولر (`agent_am/services/scheduler_service.py`):** APScheduler کی مدد سے پاکستان ٹائم کے مطابق خودکار روزانہ ورک فلو۔
6. **مستقل ڈیٹا بیس (`agent_am.db`):** SQLite / PostgreSQL مع خودکار تکرار سے بچاؤ (Duplicate Prevention Constraints)۔
7. **یومیہ اردو رپورٹس آرکائیو (`reports/`):** روزانہ کی بنیاد پر Markdown اور HTML میں تفصیلی آڈٹ رپورٹس کا مستقل ذخیرہ۔

## 🚀 4. انسٹالیشن اور چلانے کا طریقہ (Quick Start)

### مرحلہ 1: پیکجز کی تیاری
ورچوئل ماحول بنائیں اور درکار لائبریریز انسٹال کریں:
```bash
py -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```

### مرحلہ 2: کنفیگریشن فائل (`.env`)
`.env.example` کو کاپی کر کے `.env` بنائیں اور اپنے کریڈینشلز درج کریں:
```bash
copy .env.example .env
```
اہم متغیرات:
* `GEMINI_API_KEY` یا `OPENAI_API_KEY`: اے آئی ماڈل کی چابی
* `YOUTUBE_API_KEY`: یوٹیوب ڈیٹا اے پی آئی چابی
* `TIMEZONE="Asia/Karachi"`

### مرحلہ 3: ایپلیکیشن اسٹارٹ کریں
1. **ویب ڈیش بورڈ اور لائیو سرور:**
```bash
.\venv\Scripts\python.exe main.py
```
براؤزر میں کھولیں: `http://localhost:8000`

2. **اسٹینڈ اکیلا پس منظر ورکر (Standalone Daemon Worker):**
```bash
.\venv\Scripts\python.exe run_worker.py
```

3. **اردو ٹرمینل کنسول (CLI):**
```bash
.\venv\Scripts\python.exe cli.py
```

## ⌨️ 5. دستیاب اردو کمانڈز (Supported Urdu Commands)
آپ ڈیش بورڈ کے بٹن یا ٹرمینل میں درج ذیل احکامات دے سکتے ہیں:
* `"روزانہ آڈٹ شروع کریں"` — پورے چینل کا فوری آڈٹ اور نئی رپورٹ تیار کرنا
* `"آج کی رپورٹ دکھائیں"` — آج کی مکمل یومیہ رپورٹ اردو میں دیکھنا
* `"اگلے دو دن کی پوسٹس دکھائیں"` — 48 گھنٹوں کی قطار اور شیڈول شدہ مواد کا معائنہ
* `"شیڈول شدہ پوسٹس کی تصدیق کریں"` — قطار کے مواد کی تاریخی و تکنیکی تصدیق
* `"ناکام کاموں کی تفصیل دکھائیں"` — حالیہ ایررز یا وارننگز کا تفصیلی جائزہ
* `"ایجنٹ کا سسٹم اسٹیٹس دکھائیں"` — ماڈیولز کی لائیو ہیلتھ کا معائنہ
* `"نئی کوئز پوسٹ تیار کریں"` — مستند اسلامی تاریخ کوئز مع صحیح جواب اور حوالہ
* `"نیا ٹیکسٹ پول تیار کریں"` — فکری و معلوماتی ٹیکسٹ پول کی تیاری

## ☁️ 6. مستقل 24/7 کلاؤڈ ڈیپلائمنٹ (Docker / VPS)
اگر آپ چاہتے ہیں کہ سسٹم کمپیوٹر بند ہونے کے بعد بھی انٹرنیٹ پر مستقل چلتا رہے، تو ڈوکر (Docker) کے ذریعے چلائیں:
```bash
docker compose up -d
```
یہ کنٹینر خودکار طور پر `Asia/Karachi` ٹائم زون کے مطابق ہر روز صبح آڈٹ رن کرے گا اور شام کو پوسٹنگ کو سنبھالے گا۔
